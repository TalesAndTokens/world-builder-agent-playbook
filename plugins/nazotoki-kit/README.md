# nazotoki-kit

Tales & Tokens の world で、**謎解き・クイズラリー・周遊イベント**を作るための Claude Code プラグインです。

受付で回答券を配り、選択肢を選ばせ、正解に印を与える——この構成を一括で生成し、公開前に配線を検証します。

## 何が楽になるか

9問×3択なら、イベントは28件になります。管理画面で1件ずつ作るのは現実的ではありません。
このプラグインは、正解表と解説を書いたファイルから、**アイテムとイベントをまとめて作ります**。

**イベント10件の無料枠だけで、謎解きを1本作れます**（4問×2択、または3問×3択）。
回答用のウェブサイトも必須ではありません。問題シートにQRを直接印刷すれば成立します。

## 導入

先に **world-builder プラグイン**を入れてください。MCP サーバーの設定と、world の基本操作のスキルが入ります。

```
/plugin marketplace add TalesAndTokens/world-builder-agent-playbook
/plugin install world-builder@tales-and-tokens
```

続けてこのプラグインを入れます。

```
/plugin install nazotoki-kit@tales-and-tokens
```

## 使い方

Claude Code で「謎解きイベントを作りたい」と伝えてください。`nazotoki` スキルが、
構成の決め方から順に案内します。

| スキル | 役割 |
|---|---|
| `nazotoki` | 全体像。構成の選び方、無料枠の件数計算、作問の注意点、人間がやること |
| `nazotoki-setup` | `flavor.json` と `event.json` から world を一括構築する |
| `nazotoki-check` | 公開前に配線を検証する |

## ファイル

| | |
|---|---|
| `flavor/plain/flavor.json` | 世界観の雛形。回答券と印の名前・文言 |
| `examples/free-4x2/event.json` | 無料枠に収まる例（4問×2択＝9件） |
| `docs/data-format.md` | データ形式と、World Builder への変換規則 |

意匠（アイコンや画像）は同梱していません。**画像は任意**で、無くても登録できます。
必要なら回答券と印の2枚を用意してください。

## 注意

- **受付イベントのURLは秘密です。** 回答券が手に入る入口なので、印刷物にだけ載せ、ウェブサイトには置かないでください
- **現地調査は作問より先に行ってください。** 掲示できない場所に選択肢を置くと、問題が成立しません
- **公開前に `nazotoki-check` を実行してください。** 印は1種類で個数を数える方式なので、配線を1件間違えると全員がクリアできてしまいます

## ライセンスと表記

このプラグインが作るのは world の構成だけです。企画の内容、問題文、画像、ブランドは
利用者のものになります。

同梱の `flavor/plain` は自由に複製・改変してかまいません。

## バージョン

0.1.0。仕様は変わる可能性があります。
